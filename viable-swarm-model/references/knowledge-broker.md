# VSM Knowledge Broker — Cross-Skill Digest
> Updated by: `knowledge-broker.sh` (SessionEnd hook)
> Read by: All three skills at Phase 0

This file bridges the three VSM skills (main, coach, gym) by explicitly
surfacing what each skill has learned, so the others can act on it.

## How to Use This File

**Main skill (Phase 0)**: Read this file to learn what traps coach has planned
and which hypotheses gym has recently validated. Adjust your build strategy.

**Coach (Phase 0a)**: Read this file to learn main skill's recent gaps and
gym's confirmed patterns. Design build traps that target known weaknesses.

**Gym (Phase 0)**: Read this file to learn main skill's recurring failures and
coach's scored gaps. Prioritize hypotheses that address active pain points.
